# Minimum Stack

## Problem Description

Design a stack that supports push, pop, top, and retrieving the minimum element in O(1) time.

Example:
- Push 5, Min = 5
- Push 10, Min = 5
- Push 3, Min = 3
- Push 8, Min = 3
- Pop (removes 8), Min = 3
