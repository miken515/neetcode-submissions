# Find Median In A Data Stream

## Problem Description

Design a class to find the median of a data stream.

The median is the middle value in an ordered integer list. If the list has an even number of elements, the median is the average of the two middle elements.

For example:
- For [1, 2] -> 1.5
- For [1, 2, 3] -> 2
